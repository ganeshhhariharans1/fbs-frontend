
# FBS Consultancy Site (Fullstack)

## 🔧 Structure
- `frontend/` – React frontend (deploy on Vercel)
- `backend/` – Flask backend (deploy on Render)

## 📦 How to Deploy

### Frontend (React)
1. Go to https://vercel.com
2. Import frontend folder as new React project
3. Done.

### Backend (Flask)
1. Go to https://render.com
2. Create a new Web Service
3. Upload `server.py`
4. Add environment variables:
   - EMAIL_ADDRESS=buildwithfbs@gmail.com
   - EMAIL_PASSWORD=your-app-password
5. Add `requirements.txt`
